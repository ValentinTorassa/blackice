# Evidence

A capability counts as working only when it has an entry here. Entries come only from real runs by the people
building blackice.

## One file per run

Name the file after the checkpoint and what it shows, for example `P0-02-real-deny-linux.md`. The site reads the
`P0-xx` prefix to mark that checkpoint as recorded, so add the file only after the run is real.

Each entry records:

- **Claim**: one sentence, and the checkpoint it covers.
- **Platform**: OS, kernel or macOS version, architecture, and on macOS whether SIP is on.
- **Build**: commit hash and Zig version.
- **Policy**: the policy file used, inline or linked.
- **Run**: the exact commands.
- **Result**: what was observed, including the enforcement point (kernel, proxy or resolver).
- **Receipts**: the receipt lines, or a link to them.
- **Recording**: a link, if there is one.
- **Limits**: what this run does not show.
- **Date**.
