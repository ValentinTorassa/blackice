# CLI

The commands. `blackice help COMMAND`, or `blackice COMMAND --help`, shows a command's options.

| Command | What it does |
| --- | --- |
| `blackice start [--config PATH]` | Start filtering with `~/.config/blackice/blackice.toml`, or PATH, asking a few questions first when there is no file. Run it again after editing the file or upgrading. A mode or answerer switched since the last start stays while the file's own `mode` and `answers` are unchanged. |
| `blackice stop` | Stop filtering and remove the network extension. |
| `blackice status` | The mode, who answers, what waits, the rules, the approvals and the timeout. |
| `blackice mode accept-all \| ask \| block-all [--agent NAME]` | Switch the mode. `--agent` picks who answers in ask mode: `fx`, `claude-code`, `codex`, `opencode` or `you`; its hook must be in `blackice.toml`. Connections that wait go on if the new mode lets them through, and are dropped otherwise. |
| `blackice pending` | What waits, each with the `blackice approve` line that lets it through, then the approvals and the denials of the last 10 minutes, with the time each has left. |
| `blackice approve --app ID [--team TEAM] --host HOST [--for 1h]` | Let one app reach one host, and its waiting connections through. `--for` takes seconds, minutes or hours (`30s`, `10m`, `1h`), at most 24 hours; 1 hour by default. |
| `blackice deny --app ID [--team TEAM] --host HOST` | Drop the app's waiting connections to that host and remove its approval. For 10 minutes its new connections there are dropped without asking. |
| `blackice report [--last 1h]` | What the filter dropped, by reason and app, over the last `30m`, `2h` and so on, up to `168h`. In accept-all, what ask mode would have done. No Touch ID. |
| `blackice agent connect NAME [--model NAME] [--config PATH]` | Set `fx`, `claude-code`, `codex` or `opencode` up to answer in ask mode. See [Let an agent answer](/docs/install#let-an-agent-answer). |
| `blackice agent install` / `uninstall` | Start the daemon that runs the hooks, now and at each login, or stop it. `agent connect` starts it for you. |
| `blackice menu [--login on \| off]` | Show blackice in the menu bar until you quit it. `--login on` also opens it at each login, `--login off` stops that. |
| `blackice init [--config PATH]` | Ask `start`'s questions and write the file, without starting. It never replaces a file. |
| `blackice validate PATH` | Check a `blackice.toml` without loading it. |
| `blackice version` | The version and build. |

`start`, `stop`, `mode`, `approve` and `deny` ask for Touch ID, or your login password.

`--team` is the app's Team ID; leave it out for Apple's own code. `--cdhash HEX`, in place of `--app`, names ad hoc signed code by the CDHash that `codesign -dvvv` prints. `--host` takes a host name, or an IP address for a [connection with no name](/docs/configuration#connections-with-no-name), as `pending` shows it. Hooks do not use `approve` and `deny`: they [answer on their last line](/docs/configuration#how-a-hook-answers).

Exit statuses: 0 done, 64 a usage error, 65 an invalid `blackice.toml`, 66 no file to read, 69 not the signed Blackice.app, or the filter did not answer, 70 a macOS request failed, 73 `init` found a file already there, 75 run it again (after restarting the Mac, when blackice says so), 77 Touch ID cancelled, 130 a setup stopped by Control-C.
