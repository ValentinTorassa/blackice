# Introduction

netshield is a headless network extension and CLI for macOS, where an agent can approve each new connection.

<Planned />

netshield is a network extension, a small daemon and a CLI. The extension sees every new outbound connection on the Mac, from any app. There are three modes. Accept all lets everything through, block all drops everything that no rule allows, and ask pauses each new connection that no rule covers while a hook asks an agent what to do.

The agent answers on the command line, for example `netshield approve --app com.example.tool --host example.com --for 1h`. Nobody has to click a dialog.

## Why

Agents run on developer machines all day and need to make network decisions without a person at the keyboard. The code that sees every connection on a machine is also a sensitive place for a dependency, so the aim is to keep netshield small and without third-party dependencies.

## Relation to blackice

[blackice](https://github.com/ValentinTorassa/blackice) confines one command and everything it starts, with a fixed policy file, and never asks. netshield covers the whole machine and asks an agent about each new connection. It starts from blackice's macOS app filter: the Network Extension, app identity from code signatures, and the TLS server name reader.
